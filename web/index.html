Limits and supported files

See the format descriptions above for supported file types. Macro-enabled, password-protected and digitally signed packages cannot be processed. Package expanded limit: 250 MiB, up to 5,000 entries and 50 MiB per entry. Embedded images above 25 megapixels stay unchanged; larger standalone images are rejected. PNG color reduction supports static images up to 4 megapixels and 8-bit samples; other variants use lossless processing. Unsupported JPEG variants, including CMYK, stay unchanged.
